# Sprint_6
<sub>Проект выполнен по структуре POM:</sub>
<sub>Файл requirements.txt содержит все необходимые для запуска тестового прогона зависимости</sub>
<sub>Файл conftest.py содержит используемые во всех тестах фикстуры</sub>
<sub>Файл data.py содержит используемые в тестах наборы данных</sub>
<sub>Директория locators содержит используемые в тестах локаторы: файл с общими локаторами и отдельные файлы для каждой тестируемой страницы</sub>
<sub>Директория pages содержит используемые в тестах методы взаимодействия с элементами страниц: отдельные файлы для каждой тестируемой страницы</sub>
<sub>Директория tests содержит тестовые сценарии: отдельный файл для каждого тестируемого функционала</sub>
<sub>Директория allure_results содержит файлы с отчётом по последнему прогону всех тестов из директории /tests</sub>

**Перечень реализованных тестов:**
test_faq.py
1. Тесты 1-8: test_faq_answers
*Проверка текста каждого вопроса из раздела FAQ с ожидаемым*

2. Тесты 9-10: test_logos_navigation.py
*Проверка переходов по корректным конечным URL'ам при кликах на логотипы*

3. Тесты 11-12: test_order_scooter.py  
*Проверка успешного создания заказа аренды самоката. Два теста, по одному на каждую точку входа на страницу заказа с использованием двух разных наборов пользовательских данных*

**Прим.:**
*Для оптимизации времени прогона все тесты параметризованы. Для запуска тестов используется скоуп "module": каждый test_.py запускает свою сессию драйвера браузера. Все тесты из одного test_.py проходят за одну сессию драйвера, но логируются в Allure отдельно.*
